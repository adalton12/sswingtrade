📈 CAPITAL MANAGEMENT FLOW (Dinâmico com Juros Compostos)

Week 1:
  Inicial: R$ 0
  + Base Semanal: R$ 500
  = Saldo Semana 1: R$ 500
      ├─ Max Daily Allocation: R$ 100/dia
      └─ Max Weekly: R$ 500

Week 2:
  Anterior: R$ 500
  + Lucro Semana 1: R$ 50 (exemplo)
  + Base Semanal: R$ 500
  = Saldo Semana 2: R$ 1.050 ← REINVESTIMENTO (Juros Compostos!)
      ├─ Max Daily Allocation: R$ 100/dia (escalável com crescimento)
      └─ Max Weekly: R$ 500

Month 2:
  Anterior: R$ 1.050
  + Lucro Acumulado: R$ 150
  + MONTHLY_DEPOSIT: R$ 500 (1º dia útil do mês)
  = Saldo Mês 2: R$ 1.700 ← CRESCIMENTO EXPONENCIAL

  capital_history tabela registra TODAS as transações:
  ├─ deposit      : Aporte inicial/mensal
  ├─ trade_pnl    : Lucro/perda em cada posição
  ├─ reinvestment : Cálculo automático de juros compostos
  └─ monthly_deposit: Aporte mensal automático

  ├─ Bollinger Bands
  └─ Volume Spike

  ├─ Event Type Detection
  └─ Confidence Level

ML Probability (30%)
  ├─ P(High >= 2% in 3 days)
  ├─ P(High >= 4% in 5 days)
  ├─ XGBoost/LightGBM Model
  └─ Ensemble Prediction

Volume/Momentum (20%)
  ├─ Volume Spike Detection
  ├─ Momentum Indicators
  └─ Liquidity Check

              ↓ (Weighted Average)

              └─ NO  → Rejected

🔐 RISK ENGINE (Inviolável)

Every Order Must Pass:

1. Capital Check
   └─ Available Balance >= Order Amount?

2. Daily Limit
   └─ Remaining Today >= Order Amount?

3. Weekly Limit
   └─ Remaining Week >= Order Amount?

4. Stop Loss
   └─ 1.5x ATR from entry price

5. Take Profit
   └─ Risk:Reward >= 1:2 ratio

6. Circuit Breaker
   └─ Daily Loss < 1.5% of Total Capital?

                ▼
        ALL CONDITIONS MET?
                ├─ YES → Send to Paper Broker
                └─ NO  → Reject + Log Reason
